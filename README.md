\# CODSOFT Artificial Intelligence Internship



This repository contains the tasks completed as part of my CodSoft Artificial Intelligence Internship.



\## Tasks



\### Task 1: Chatbot with Rule-Based Responses

A simple Python chatbot that responds to user inputs using predefined rules, if-else statements, keyword matching, and basic conversation flow.



\### Task 2: Tic-Tac-Toe AI

A Tic-Tac-Toe game where a human player plays against an AI. The project includes Easy Mode using random moves and Hard Mode using the Minimax algorithm, making the AI unbeatable.



\### Task 3: Image Captioning AI

An image captioning application that uses a pre-trained BLIP transformer model to generate natural language captions for uploaded images. The project includes image upload, caption suggestions, editable final captions, caption history, and a Streamlit frontend.



\### Task 4: Smart Job Recommendation System



A job recommendation system that suggests suitable job roles based on candidate skills, preferred location, experience level, and job similarity.



The project uses content-based filtering with TF-IDF vectorization and cosine similarity. It also includes skill gap analysis to show matched skills and missing skills for each recommended job.



\*\*Technologies Used:\*\* Python, Streamlit, Pandas, Scikit-learn, TF-IDF, Cosine Similarity
