## 🤖 Task 01 — Rule-Based Chatbot

> *Building conversation intelligence from the ground up — no neural nets needed.*

A Python-powered chatbot that simulates natural conversation through carefully crafted rules, keyword matching, and structured response logic.

**✨ Features**
- 🧠 Rule-based conversation engine with keyword matching
- ⚡ Quick-reply suggestion buttons
- 💬 Persistent chat history within session
- 🎨 Clean, interactive Streamlit UI

**🛠 Stack:** `Python` `Streamlit` `Rule-Based Logic` `String Processing`

---

## 🎮 Task 02 — Tic-Tac-Toe AI

> *Easy Mode: a warm-up. Hard Mode: mathematically unbeatable.*

A fully playable Tic-Tac-Toe game pitting humans against an AI opponent that thinks several moves ahead using the Minimax algorithm.

<div align="center">

| Mode | AI Strategy | Can You Win? |
|------|-------------|-------------|
| 🟡 Easy | Random moves | Yes! |
| 🔴 Hard | Minimax Algorithm | Never. |

</div>

**✨ Features**
- 🎯 Human vs AI with two difficulty levels
- 🧩 Minimax algorithm for perfect, unbeatable play
- 🏆 Win, loss, and draw detection
- 🔄 Instant game reset

**🛠 Stack:** `Python` `Streamlit` `Minimax Algorithm` `Game AI`

---

## 🖼️ Task 03 — Image Captioning AI

> *Upload any image. Watch AI describe it in plain English.*

An end-to-end deep learning application powered by **BLIP** (Bootstrapped Language-Image Pretraining) — one of the most capable vision-language transformer models available.

**✨ Features**
- 🖼️ Drag-and-drop image upload
- 🤖 Auto-generated captions via BLIP transformer
- ✏️ Editable caption refinement
- 🕓 Full caption history log
- ⚡ Real-time inference with Streamlit

**🛠 Stack:** `Python` `Streamlit` `Hugging Face Transformers` `BLIP` `PyTorch` `Pillow`

---

## 💼 Task 04 — Smart Job Recommendation System

> *Not just "here are some jobs" — but "here's what you're missing to get your dream job."*

A content-based recommendation engine that matches candidates to the most relevant job roles — and delivers a skill gap analysis showing exactly what to learn next.

**✨ Features**
- 🎯 Personalized job matching with TF-IDF + Cosine Similarity
- 📍 Filter by location and experience level
- 🔍 Skill gap analysis — matched skills vs. missing skills
- 📊 Match score percentages for each recommendation
- 🌐 Interactive Streamlit dashboard

**🛠 Stack:** `Python` `Streamlit` `Pandas` `Scikit-learn` `TF-IDF` `Cosine Similarity`

---

## 👤 Task 05 — FaceVision AI

> *Register a face. Train the model. Let AI recognize you — in real time.*

A full Computer Vision pipeline for face detection and recognition, built with OpenCV's Haar Cascade and LBPH algorithms.

**✨ Features**
- 📸 Live face detection via webcam
- 🗂️ Face enrollment & dataset creation
- 🏋️ On-device model training (LBPH)
- 🔍 Real-time recognition with confidence scores
- 👥 Multi-user registration support
- 📊 Streamlit management dashboard

**🛠 Stack:** `Python` `OpenCV` `Streamlit` `NumPy` `Haar Cascade` `LBPH Face Recognizer`
